# Drama Agent UI/UX 分析（竞品：MiniCut / SceneMixer）

> 方法：用 [ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)（MIT）的优先级规则（1 无障碍 → 10 图表）与本地知识库检索（`--design-system` + `--domain ux`），对照两家竞品首页公开可见的部分，审计当前 `web/index.html`。
> 局限：两家竞品的工作台需要登录，本分析只覆盖营销页和公开流程描述，没有体验它们的内部编辑器。
> 日期：2026-10-20

---

## 1. 竞品拆解

| 维度 | MiniCut | SceneMixer | Drama Agent（现状） |
|---|---|---|---|
| 定位 | 专业 AI 视频工作台（76 个模型、节点画布、3D 场景、剪辑、MCP） | AI 短剧生产机器（小说/剧本 → 成片，15 种语言） | 剧本/小说 → 成片的自动流水线（单模型链路） |
| 主题 | 深色 `#141414`，白字，冷青渐变标题 | **浅色** `#FFFFFF`，Apple 风；首屏是全幅人物大图圆角卡 | 深色 `#030607`，荧光绿 `#D4FF3A` 强调 |
| 字体 | 标题 Space Grotesk 68px / 700；正文 Inter | 标题 Manrope；正文 SF Pro | 系统字体（Inter / PingFang），标题 30px |
| 按钮 | 胶囊形（9999px）描边 | 10px 圆角，白底黑字 + 半透明次按钮 | 8px 圆角，荧光绿主按钮 |
| 首屏叙事 | 「一个想法 → 剧本、选角、每个镜头」+ 6 张功能卡（Canvas / Cast library / Models / 3D / Templates / Your series） | 「剧本进，成片出」+ 两个按钮（开始创作 / 看样片）+ 一行说明「支持粘贴文本、上传 txt / docx」 | 直接进入工具（上传剧本表单） |
| 流程表达 | 5 个模块视频：一页式建项目 → 节点编辑器 → Agent → 剧本编辑器 → 剪辑 | **三步**：剧本 → 解析（角色/场景/分集 + 设定图）→ 出片 | 5 阶段卡片：剧本解析 → 角色与场景 → 分镜与提示词 → 视频生成 → 成片合成 |
| 成本透明 | ★ 每次生成的积分价写在按钮上，确认后才扣费；Agent「花钱前先问」；所有花费进审批列表 | 按秒扣积分；「不满意的段改脚本重来，**只为重生成的那段付费**」；首个项目免费 | 先出分镜再确认；按集出片前弹窗显示段数、秒数、出图张数（原生 confirm） |
| 一致性卖点 | Cast library：「第四集和第一集是同一张脸」 | 设定图跨集同一张脸 + 「世界模型」（360° 片场、机位解算） | 资产先行（Asset-First）：角色三视图 + 场景图作为参考图 |
| 局部重做 | ★ 改一句剧本，只重做受影响的镜头 | 改某段脚本重新生成该段 | 只能整阶段 `--force` 重跑；网页没有单段重做入口 |
| 样例/模板 | 模板卡片标「13 shots · 4 cast · 4 places · 60s」+ 积分价 | 样片卡片标「5 个角色 · 2 个场景」+ 画风标签 | 无 |
| 资产管理 | Cast library、Your series | 顶栏「资产库」 | 资产只存在于单个项目内 |
| 进阶接入 | MCP（Claude Code / Codex，50 个工具） | — | HTTP API + Agent Skill（`SKILL.md`） |

**结论**：两家共同的 UX 核心是 **「成本可预期 + 可局部返工 + 角色可复用」**。MiniCut 走「专业、可控」，SceneMixer 走「简单、批量」。我们的流水线、小说改编和 short-drama-factory 机检在功能上接近 SceneMixer，界面上更接近 MiniCut 的深色工作台。

## 2. 现状审计（按 ui-ux-pro-max 优先级）

| 优先级 | 规则 | 现状（实测） | 结论 |
|---|---|---|---|
| 1 无障碍 | 文字对比度 ≥ 4.5:1 | `--mute` 5.9～6.0:1 ✅；**`--faint` 2.8～3.0:1 ❌**（用在章节标题、时长、元信息、空状态） | 必修 |
| 1 无障碍 | 键盘焦点可见（ux：Focus States，High） | 输入框 `outline:none`，只靠边框变色；按钮/标签页/项目列表没有 `:focus-visible` 样式 | 必修 |
| 1 无障碍 | 拖拽需有单指针替代（ux：Dragging Movements，High） | 上传区是 `<div onclick>`，不可聚焦；键盘用户只能走「粘贴」 | 必修 |
| 1 无障碍 | aria / 语义 | 全页 0 个 `aria-*` / `role`；进度条、阶段卡、状态点没有可读文本；日志没有 live region | 必修 |
| 2 交互 | 触控目标 ≥ 44×44 | `.btn` 约 34px，项目列表约 36px，分段按钮约 36px | 应修 |
| 2 交互 | 加载反馈 | 有阶段卡片和已用时；单段视频进度只在日志里 | 可改进 |
| 4 风格 | 不用 emoji 当图标（Pre-Delivery Checklist） | 用了 ✦ ⇪ 📄 ▶ ⏸ ★ ✔ ✘ | 应修，换 SVG（Lucide） |
| 5 布局 | 375px 不横向滚动 | 已实测 375px 无横向滚动 ✅ | 通过 |
| 6 字体颜色 | 正文 ≥ 12px | 4 处 11px（阶段编号、标签）；正文 14px（skill 建议 16px） | 应修 |
| 6 字体颜色 | 状态不能只靠颜色 | 侧栏项目状态只有圆点颜色 | 应修，加文字或图标 |
| 7 动效 | 尊重 `prefers-reduced-motion` | 未处理 | 应修 |
| 8 表单反馈 | 错误贴近字段；成功要有反馈 | 错误统一在底部；付费确认、令牌输入用原生 `confirm/alert/prompt`（5 处） | 应修，换成应用内对话框和 toast |
| 9 导航 | 深链接、可预期的返回 | 项目用 `#id` 深链 ✅；标签页切换不进历史记录 | 可改进 |

**skill 推荐的设计系统**（检索词 `AI video generator creative studio`，第一次检索返回「运营看板」不合适，按 skill 规则重试一次）：
- 风格：**AI-Native UI**（极简框架、流式反馈、上下文卡片）
- 字体：**Space Grotesk（标题）+ DM Sans（正文）**，和 MiniCut 标题字体一致，适合科技创作工具
- 配色：skill 给的是紫 `#7C3AED` + 粉 `#EC4899` 的通用「AI 紫」。**不建议采用**：它会把我们和大量 AI 产品混为一谈；两家竞品都刻意避开了紫色。建议保留现有「深色 + 荧光绿」品牌色，只修对比度（见 §4）。

## 3. 机会点（竞品有、我们缺，按价值排序）

1. **成本前置到按钮上**（学 MiniCut）：「生成第 1 集视频 · 9 段 / 60 秒 / 7 张图」直接写在按钮或按钮下方；确认弹窗改成应用内对话框，列出明细和预估价格（需要网关单价配置）。
2. **单段重做**（两家都有）：分镜页每段加「改提示词 / 重新生成本段」，只为这一段付费。后端已支持跳过已有段，只需加删除单段并重跑的接口。
3. **角色库跨项目复用**（MiniCut Cast library / SceneMixer 资产库）：把已出图的角色和场景存进全局资产库，新项目可以直接选用，第二部剧不用重新出图。
4. **样例与模板**（两家都有）：首页给 3～5 个样例项目卡片，标「10 集 · 13 角色 · 60s/集 · 小说改编」，点进去能看分镜和成片，降低新用户的不确定感。
5. **首屏一句话价值 + 三步流程**（学 SceneMixer）：新建页顶部用三步图示「上传剧本 → AI 拆解（免费）→ 按集出片（付费）」，把「免费 / 付费」的边界讲清楚，这是我们「先出分镜再确认」的差异化卖点。
6. **把机检做成质量卖点**：short-drama-factory 机检通过 / WARN 已经在概览里显示，可以升级成每集一张「质量卡」（钩子类型、断章公式、台词字数、语速），这是两家竞品没有展示的。

## 4. 建议的改版方案

### P0：无障碍与一致性（约半天，不改布局）
- `--faint` 从 `.34` 提到 `.52` 以上（对比度达到 4.5:1），并把它从正文信息里撤下，只用于装饰。
- 全局 `:focus-visible { outline: 2px solid var(--acc); outline-offset: 2px }`，去掉输入框的 `outline:none`。
- 上传区改为 `<label for=file>`，可以用 Tab 聚焦、按 Enter 打开；保留拖拽。
- 进度条加 `role="progressbar" aria-valuenow`；日志加 `aria-live="polite"`；阶段卡加 `aria-current="step"`；状态点旁边加文字。
- emoji 全部换成内联 SVG（Lucide：upload、file-text、play、pause、check、x、sparkles）。
- 最小字号 12px；按钮和列表项最小高度 40～44px。
- 加 `@media (prefers-reduced-motion: reduce)`，关闭过渡动画。
- 原生 `confirm/alert/prompt` 换成应用内对话框和 toast。

### P1：竞品对齐（1～2 天）
- 字体：标题用 Space Grotesk，正文用 DM Sans，加载失败时回退系统字体。中文仍由 PingFang / 微软雅黑兜底。
- 新建页：顶部加三步流程条，标出免费 / 付费边界；交付方式默认「先出分镜」。
- 按集出片：费用明细写在按钮上；分镜页加「重新生成本段」。
- 项目页：每集一行改成「集卡片」，包括封面（第一段首帧）、机检质量、状态、操作。

### 完成情况（2026-10-20，按 frontend-design skill 改版 `web/index.html`）
- **P0 全部完成**：
  - `--faint` 现为 .54，实测对比度 5.3～5.5:1；`--mute` 为 .66，7.2～7.7:1。
  - 全局 `:focus-visible` 已加，`outline:none` 已移除。
  - 上传区改为 `<label>`，文件输入框可以用 Tab 聚焦。
  - 已加 progressbar、`aria-live` 日志、track 的 `aria-current="step"`；侧栏状态有文字。
  - emoji 全部换成内联 SVG。
  - 最小字号 12px，控件高度 ≥36px（多数 40px）。
  - 已支持 reduced-motion。
  - `alert/prompt/confirm` 换成 toast 和 `<dialog>`。
- **P1 已完成**：
  - Space Grotesk + DM Sans；
  - 新建页三步流程条，随进度变化；
  - 项目页「集卡片」：9:16 画框和大号集数，出片后显示该集真实画面，带机检、状态和操作；
  - 五个阶段改成连线轨道，按集出片时显示「已出片 x/N 集」。
- **P1 未做**：分镜页「重新生成本段」（需要后端接口）。
- **顺手修复**：侧栏项目列表每 15 秒重绘一次，导致点击偶尔丢失，已改为事件委托。

### P2：差异化（视需求）
- 全局资产库（角色和场景跨项目复用）
- 样例项目和模板
- 单价配置后显示预估金额
